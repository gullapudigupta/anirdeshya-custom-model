Recommended route

Existing code-capable model + approved versioned documentation + hybrid RAG + deterministic tools + explicit permissions. Start read-only, add repository evidence, then previewable patches and isolated validation. Train only when measurements show a remaining behavioral gap.

Reading order: Overview, strategy, requirements, design, then the specialist plans below.

Hardware, thresholds, costs, and timelines are planning estimates. No model has been selected or benchmarked. The folder name is an organizational label, not a model-availability claim.
